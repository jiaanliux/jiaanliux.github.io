Project 1

UrbanAgents — LLM Agent Harness for Geospatial Urban Simulation

Role I designed and built UrbanAgents, a reproducibility-first agent-based modelling harness for LLM-driven agents (100–1000 scale), including the React/Vite web interface. I grounded the agents in high-resolution geospatial infrastructure and 15-minute reachability logic, and built scenario pipelines for heatwave resilience and healthcare accessibility, turning complex spatial data into decision-support.

PythonGeoPandas / GDAL LLMsagent-based modelling React + VitePlotly
  • Code: github.com/UNU-Macau/QuarterSociety (version for the published paper)
  • Paper: Liu, J., et al. (2026). Cognitive urban simulation with large language models: Agent-based modeling under the fifteen-minute city paradigm. In AI for Humanity: Building an Equitable Digital Future. Springer.
Project 2

EnvironMax — Intelligent Urban Environmental Health Risk Platform

Role I was the main researcher and developer of EnvironMax, an AI + geospatial platform that brings together multi-source data including geospatial layers and points-of-interest (POI) data, IoT sensors, GPS traces, mobile sensing, and meteorological feeds to produce dynamic, location-based environmental health-risk assessments and personalized healthy-living routing. I designed the spatial risk-assessment algorithm and the map-based interface, and the work was published in Urban Climate (Q1, IF 6.4).

PythonGIS analytics GeoDjangoIoT / GPS risk modellingmap visualization
  • Paper: Navigating to urban environmental health: Professionalized and personalized healthy living assistant based on intelligent health risk management. Urban Climate (2021).
    doi.org/10.1016/j.uclim.2021.101020
Project 3

SYSU-HiRoads + VLG — Framework for Road Hierarchy Classification

Role I co-led the public release of SYSU-HiRoads, a large-scale, multi-level remote-sensing road dataset (~3,631 km2 of satellite imagery at 0.8 m resolution), and co-authored the companion vision-language-geometry (VLG) method for fine-grained road hierarchy classification. I prepared the dataset documentation for external researchers and wrote the UNU Macau article announcing the release, so the wider remote-sensing community can build on it for transport-infrastructure mapping and disaster-response work.

PythonPyTorch Vision-Language ModelsGDAL GeoPandasremote-sensing imagery
  • Paper: A Large-Scale Remote Sensing Dataset and VLM-based Algorithm for Fine-Grained Road Hierarchy Classification.
    arxiv.org/abs/2603.21222
  • Dataset (openly released): doi.org/10.5281/zenodo.18642747
  • UNU Macau article: go.unu.edu/Launching-SYSU-HiRoads
Project 4

UNU Macau FutureWork AI Platform & Multi-Cloud Service Infrastructure

Role As UNU Macau's ICT Focal Point, I designed, deployed, and operate our multi-cloud service portfolio. I built FutureWork Studio, a modular FastAPI portal with a React front-end, integrating the AI and automation tools and workflows I developed to streamline daily research and operations, all secured behind Entra ID / OAuth2-Proxy single sign-on.

Deployment I keep all of this in a single IaC repository across AWS, Azure and Cloudflare with templated docker-compose files plus per-server environment files. I use Git/GitHub with branch protection, stage releases from dev/staging on-prem to production on AWS with a manual sign-off, can roll back to a previous image tag within minutes, and run scheduled database/volume backups for disaster recovery. My routine update is simply git pull && ./deploy.sh.

Project 5

UNU Macau Project-Websites Platform

Role I designed and built UNU Macau's project-websites platform from scratch. It is a single FastAPI application that serves multiple research microsites from one codebase, with a hub index, per-project routers, and a reusable template so new sites stay consistent. An OpenCode AI layer is integrated to enable internal researchers to create new sites with their project documentation within minutes, leveraging LLM coding agents. The first live site is ReModelUN, an interactive learning hub I built for a summer training camp.

Python (FastAPI)Jinja2 Tailwind CSSDockerGit/GitHub
  • ReModelUN (live): projects.unu-macau.org/ReModelUN
Project 6

Tessera — Agentic AI for Large-Scale Content Analysis (NLP)

Role I designed and built an end-to-end agent harness (framework) for large-scale qualitative data analysis. (One research use case is that we are using it to analyze large-scale social media corpus data on online misogyny for a UN Women research project.) Tessera is a multi-tenant platform (FastAPI + PostgreSQL backend, React + Vite front-end I wrote) with a YAML recipe DSL, fault tolerance that lets failed documents resume rather than crash, content-addressed caching for byte-level reproducibility, a web monitoring UI, and full audit trails (prompt hashes and run manifests).
